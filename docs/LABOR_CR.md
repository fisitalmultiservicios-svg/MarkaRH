# Reglas laborales de Costa Rica

Esta entrega registra evidencias; no implementa cálculo legal ni nómina. La especificación funcional original sigue siendo la referencia para las fases siguientes.

Las jornadas diurna, mixta y nocturna, descansos remunerados/discontinuos, contratos inferiores al máximo legal, excepciones y feriados deben modelarse como reglas versionadas y revisables. Los turnos que cruzan medianoche no se dividen automáticamente en jornadas diferentes.

Las marcaciones no equivalen necesariamente a trabajo efectivo. Distinguir hechos, intervalos interpretados, horas detectadas, solicitadas, autorizadas, trabajadas y propuesta de pago. Preservar siempre las evidencias originales y documentar toda corrección.

No inferir ausencias de una terminal desconectada. No inventar horas a partir de eventos incompletos. No estimar aguinaldo sin historial completo de remuneraciones. Validar la norma vigente y los contratos con asesoría laboral antes de introducir cálculos monetarios.

Fuentes para revisión: Código de Trabajo (PGR/SINALEVI, Ley 2), orientación MTSS y Ley 8968/PRODHAB para tratamiento de datos. No se certifica cumplimiento normativo mediante esta base de código.
